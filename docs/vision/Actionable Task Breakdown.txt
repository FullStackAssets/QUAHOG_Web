ACTIONABLE TASK BREAKDOWN

How to Read This List

Recognition Key — every task carries these markers:

Marker Meaning
🔴 CRITICAL Blocks other work. Do first. Cannot ship without.
🟠 CORE Defines the game. Non-negotiable.
🟡 ENHANCE Makes it better. Cut if needed.
🟢 STRETCH Polish. Cut first.
⚡ QUICK WIN High impact, low effort. Do early.
🔗 BLOCKED BY Depends on another task.
📦 DELIVERABLE Produces a concrete artifact.
👤 OWNER Team responsible.
⏱ EFFORT Rough time estimate.

Phases:

· P0 — Pre-Production (months 0–6): Prove the vision.
· P1 — Foundation (months 6–18): Build the engine and core systems.
· P2 — Production (months 18–42): Build the world and content.
· P3 — Alpha (months 42–48): All features in, content complete.
· P4 — Beta (months 48–54): Polish, optimize, fix.
· P5 — Launch (months 54–60): Ship and support.

THE CRITICAL PATH — 10 TASKS THAT BLOCK EVERYTHING

If any of these slip, the whole project slips. Track these daily.

□ 🔴 📦 P0 · 2w · Creative Director — Write the Minimum Viable World document: the smallest version of this game that still delivers interiors + pedestrian/traffic AI + police escalation + vehicle damage/handling + dynamic weather/lighting. Get it signed off. This document governs every cut decision.
□ 🔴 📦 P0 · 4w · Tech Director — Build the simulation clock + environment simulator skeleton. Everything reads from this. Nothing else starts until it exists.
□ 🔴 📦 P0 · 6w · Engine Team — Build the ECS + job system + spatial partitioning. Every NPC, vehicle, and prop runs on this.
□ 🔴 📦 P0 · 4w · Engine + Narrative — Build the event log + persistence layer. Without this, no consequence persists.
□ 🟠 📦 P0 · 8w · Engine + World — Prototype the five core systems end-to-end in one small sandbox: one interior, one pedestrian AI loop, one police chase, one damaged vehicle, one weather cycle. Prove they feel good together before scaling.
□ 🔴 📦 P0 · 3w · QA + UX — Stand up the accessibility framework. Retrofitting is 10x harder than building it in.
□ 🔴 📦 P0 · 2w · Production — Define the definition of done for every system. No feature is "done" without: functional, tested, accessible, performant, documented.
□ 🔴 📦 P0 · 2w · Tech Director — Build the build + playtest pipeline. Every team must be ≤2 weeks from a playable build.
□ 🔴 📦 P0 · 4w · Tools Team — Ship v0.1 of the world editor (placement of props, NPCs, vehicles, missions). Content creation cannot scale without tools.
□ 🔴 📦 P0 · Ongoing · Production — Maintain the risk register and cut list from day one. Review weekly.

CATEGORY 1 — FOUNDATION & ENGINE

The machinery everything runs on.

□ 🔴 📦 P0 — Build the simulation clock (60x real-time default, locally variable, persistent across sessions).
□ 🔴 📦 P0 — Build the environment simulator (coarse grid: temperature, moisture, wind, light, fire, water level).
□ 🔴 📦 P0 — Build the ECS (entities = NPCs, vehicles, props; components = position, velocity, AI state, schedule, inventory, health, etc.).
□ 🔴 📦 P0 — Build the job system (fixed-timestep simulation at 30Hz, scheduled across cores with dependencies).
□ 🔴 📦 P0 — Build the spatial partitioning (hierarchical grid for "who is near the player / in this cell / sharing a schedule node").
□ 🟠 📦 P0 — Build the four-stage culling + LOD pipeline (frustum → occlusion → distance LOD → shader LOD, tunable per platform).
□ 🟠 📦 P1 — Build the render graph (every frame is a DAG of passes; automatic resource aliasing and barriers).
□ 🟠 📦 P1 — Build the material pipeline (node editor, shader cache with warm-up, fallback material for every asset).
□ 🟠 📦 P1 — Build the lighting pipeline (baked lightmaps + dynamic probe interpolation, forward+ pass, SSGI + probes, volumetric fog, god rays).
□ 🟠 📦 P1 — Build the post-processing chain (bloom, tone mapping, grading, TAA, motion blur, DOF, chromatic aberration, grain, vignette) with per-effect quality sliders.
□ 🟠 📦 P1 — Build the temporal upscaler (internal resolution → display; MetalFX or equivalent).
□ 🟠 📦 P1 — Build the streaming stack (asset registry, predictive streamer, priority queue with preemption, virtual texturing, geometry streaming).
□ 🟠 📦 P1 — Build the persistence stack (versioned saves, world-state snapshot, append-only event log, cloud sync, checksummed saves).
□ 🟡 📦 P2 — Build the hierarchical navmesh with dynamic updates (doors, debris) for pedestrian, vehicle, and special navigation.
□ 🟡 📦 P2 — Build the AI decision layer (behavior tree for moment-to-moment; utility system for high-level; schedule system for long-term; all reading the same world state).

Recognition cue: If Foundation is not green by end of P1, nothing else can ship. This category is the spine.

CATEGORY 2 — ENVIRONMENT & WEATHER

The world has mood.

□ 🟠 📦 P0 — Prototype dynamic time-of-day (24-hour cycle, 1440 evaluation points, no visible stepping).
□ 🟠 📦 P1 — Build the cascaded lightmap system with dynamic TOD interpolation (8–12 baked states per architectural zone, blended in real time).
□ 🟠 📦 P1 — Build the SSR system (temporal accumulation + ray-marched fallbacks, Fresnel-correct intensity, roughness-aware mips).
□ 🟠 📦 P1 — Build irradiance probe grids per interior cell (flickering fluorescents, neon wash, corner falloff).
□ 🟠 📦 P1 — Build volumetric fog + god rays (ray-marched fog with temporal reprojection, per-light god-ray scattering, height fog, participating media for headlights).
□ 🟠 📦 P1 — Build the wetness system (accumulation, runoff, puddle formation by geometry, anisotropic reflections, water beading on car paint, drying by wind/sun/exposure).
□ 🟠 📦 P1 — Build the HDR + ACES tone mapping pipeline with per-district LUTs and per-TOD grading variation.
□ 🟠 📦 P1 — Build the dynamic weather state machine (clear → overcast → rain → storm → clearing; snow; fog; heat wave) feeding all other systems.
□ 🟡 📦 P2 — Build volumetric clouds (parallax, light scattering, moving ground shadows).
□ 🟡 📦 P2 — Build seasonal variation (daylight hours, foliage state, decoration) if shipped.
□ 🟡 📦 P2 — Build the fire propagation system (fuel, wind, adjacency, smoke, light emission, spread to buildings/vehicles).
□ 🟡 📦 P2 — Build the water simulation (Fourier waves, foam, rain ripples, underwater rendering, wakes, river flow, tides).
□ 🟡 📦 P2 — Build interior lighting as gameplay (dark interiors need light sources; light switches; windows provide TOD-correct light).

Recognition cue: Weather is not decoration — it's a system input. If the weather system doesn't write to the road-grip, AI, economy, and fire systems, it's not done.

CATEGORY 13 — QA & TESTING

The difference between shipping and shipping a working game.

□ 🔴 📦 P0 — Build the integration test framework (every pair of systems tested for their interaction).

□ 🟡 📦 P2 — Build the accessibility test program (every option tested by a player with the relevant disability).
□ 🟡 📦 P2 — Build the localization test program (layout, font support, cultural appropriateness per language).

□ 🟡 📦 P2 — Establish the "would a player notice?" heuristic for emergent weirdness (develop team judgment about what matters).

Recognition cue: If a Sev 1 bug exists at launch, Category 13 failed. This category is a gate, not a phase.
